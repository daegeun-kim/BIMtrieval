MODIFICATIONS
-------------
CC BY 4.0 requires that changes be indicated. This demo does NOT ship the
original IFC file. The model was modified as follows:

  1. Converted from IFC (IFC2X3 STEP) to the That Open "Fragments" binary
     format (@thatopen/fragments 3.4.6 / web-ifc 0.0.77) for rendering in a
     browser.
  2. No geometry was added or removed in that conversion; it is a format change,
     not an edit to the building design.

The resulting file is served from this site as `model.frag`.

WHAT THIS DEMO IS
-----------------
A static page. Every answer shown was recorded in advance from a local run of
BIMtrieval against this model. There is no database, no backend, and no language
model behind this page.

Project source: https://github.com/daegeun-kim/BIMtrieval
